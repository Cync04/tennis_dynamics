Filters

For "between", use: min,max. For "in", use comma-separated values.

How Filters Work

Each filter keeps only rows that match your condition. Multiple filters are combined with AND.

  • = exact match. Example: column ServeIndicator, value 1.
  • != exclude an exact value.
  • >, >=, <, <= numeric comparisons. Example: Speed_MPH > 120.
  • between numeric range using min,max. Example: 100,130.
  • contains text match inside a value.
  • in one-of list using commas. Example: C,BC,BW.
